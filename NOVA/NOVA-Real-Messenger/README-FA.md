# NOVA — پیام‌رسان واقعی (نسخه شروع)

این پروژه یک رابط فارسی RTL و اتصال آماده به Supabase دارد. برای پیام‌رسانی واقعی، باید پروژه Supabase بسازید و تنظیمات را وارد کنید.

## فایل‌ها
- `index.html`: رابط کاربری و کد اتصال به سرور
- `supabase/schema.sql`: ساخت جداول و سیاست‌های دسترسی
- `README-FA.md`: همین راهنما

## راه‌اندازی
1. به https://supabase.com برو و یک پروژه جدید بساز.
2. از بخش SQL Editor محتوای `supabase/schema.sql` را اجرا کن.
3. از Project Settings → API آدرس Project URL و کلید `anon` یا `publishable` را کپی کن.
4. در `index.html` این دو مقدار را جایگزین کن:
   - `PASTE_YOUR_SUPABASE_PROJECT_URL`
   - `PASTE_YOUR_SUPABASE_PUBLISHABLE_OR_ANON_KEY`
   کلید `service_role` را هرگز داخل HTML قرار نده.
5. در Supabase بخش Authentication → Sign In / Providers، ورود Anonymous را فعال کن.
6. فایل را از طریق هاست استاتیک HTTPS منتشر کن (مثلاً GitHub Pages یا Netlify)؛ بعضی قابلیت‌ها در بازکردن مستقیم `file://` محدود می‌شوند.
7. دو مرورگر/گوشی مختلف باز کن، با دو کد متفاوت وارد شو، سپس پیام‌رسانی را امتحان کن.

## محدودیت امنیتی مهم
ورود فقط با کد `001` تا `033` و اسم دلخواه، هویت را ثابت نمی‌کند؛ کدها قابل حدس‌اند. این نسخه از ثبت دوباره یک کدِ قبلاً استفاده‌شده توسط یک حساب دیگر جلوگیری می‌کند، اما اگر کاربر روی دستگاه جدید باشد، بازیابی امن ندارد. برای استفاده خصوصی واقعی، باید برای هر کد یک PIN/رمز جداگانه تعریف شود و اعتبارسنجی آن در سرور انجام شود؛ صرفاً مخفی‌کردن کد در رابط کافی نیست.

## چه چیزهایی در این نسخه وجود دارد؟
- رابط واکنش‌گرا و مناسب موبایل
- ۳۳ کد ورودی قابل قبول
- نام نمایشی قابل انتخاب
- فهرست مخاطبان ثبت‌نام‌شده
- پیام مستقیم بین کاربران ثبت‌نام‌شده
- ذخیره پیام در دیتابیس مشترک
- دریافت لحظه‌ای پیام‌های جدید از طریق Realtime
- نمایش وضعیت آنلاین اولیه

## هنوز برای نسخه محصول نهایی لازم است
- PIN خصوصی/بازیابی امن حساب
- مدیریت دعوت‌نامه‌ها برای اینکه فقط ۳۳ فرد مورد نظر ثبت‌نام کنند
- رسید تحویل/خوانده‌شدن، فایل و تصویر، اعلان Push
- تست کامل امنیتی و محدودسازی نرخ درخواست‌ها
